# Guava Past — site escolar

Site demonstrativo de uma marca fictícia de bolos de goiaba, feito com HTML, CSS e JavaScript sem bibliotecas externas.

## Arquivos
- `index.html`: conteúdo e estrutura.
- `style.css`: identidade visual, layout responsivo e animações.
- `script.js`: menu para celular, animações ao rolar e ano automático.

## Publicar pelo celular Android
1. Extraia o ZIP no celular.
2. Entre em https://github.com e abra o repositório do projeto.
3. Envie `index.html`, `style.css` e `script.js` pela opção **Add file → Upload files**. Os três arquivos devem ficar na raiz do repositório.
4. Faça **Commit changes**.
5. Abra **Settings → Pages**.
6. Em **Build and deployment**, escolha **Deploy from a branch**, branch `main` e pasta `/(root)`. Toque em **Save**.
7. Aguarde alguns minutos e abra o endereço indicado na seção Pages.

Se preferir, crie cada arquivo pelo GitHub usando **Add file → Create new file**, cole o conteúdo e faça commit.
