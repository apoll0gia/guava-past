# AgroLab — modelo de site escolar

Modelo responsivo para um projeto técnico de agronegócio, feito com HTML, CSS e JavaScript simples. Não usa bibliotecas externas.

## Arquivos

- `index.html`: conteúdo e estrutura.
- `style.css`: visual, layout para celular e animações.
- `script.js`: menu mobile, animações ao rolar e ano automático.

## Como publicar pelo Android usando GitHub Pages

1. Entre em https://github.com e abra seu repositório.
2. Adicione cada arquivo pela opção **Add file → Create new file**.
3. Crie `index.html`, cole o conteúdo de `index.html` deste pacote e faça **Commit changes**.
4. Repita para `style.css`, `script.js` e `LEIA-ME.md`. Todos devem ficar na raiz do repositório, no mesmo nível.
5. Abra **Settings → Pages**.
6. Em **Build and deployment**, selecione **Deploy from a branch**.
7. Escolha a branch `main` e a pasta `/(root)` e toque em **Save**.
8. Aguarde alguns minutos e abra o endereço mostrado na área Pages.

## Personalização antes de entregar

- Troque “AgroLab” pelo nome do projeto.
- Edite o título e o texto de apresentação em `index.html`.
- Preencha objetivo, materiais, procedimentos, resultados e referências reais.
- O gráfico é apenas ilustrativo: não o apresente como resultado experimental real.
- Não inclua dados pessoais ou informações privadas.

## Dica para editar no celular

No GitHub, abra um arquivo e toque no lápis para editar. Depois de salvar com **Commit changes**, aguarde a publicação atualizar. Se a alteração não aparecer, atualize a página do site.
